Three ways to draw the T3 graph

Same task and the same 11 steps as the T3 Tutor Loop page. Each panel draws the graph a different way, so you can see which one shows what matters. Use the step bar, or the ← and → keys.

0

A

Dive and return

Time runs left to right and detour depth runs down. Shows where the focus went and how it came back.

  • Focus path
  • Active
  • Paused
  • Resolved
  • Saved for later
  • New evidence
  • No evidence
  • Uncertain
  • Missing
  • Known
B

Nested detours

Each detour sits inside the goal it interrupted. Shows what is open now, what closes it, and what it returns to.

  • The focus
  • Paused, will resume
  • Resolved, kept as one line
  • Saved for later
C

Knowledge map

Concepts are the main nodes, across tasks. Shows what the learner knows, the proof for it, and what carries over.

  • Task done
  • Current task or detour
  • Next task or saved issue
  • Prerequisite (right) · carried (left)
  • No evidence
  • Uncertain
  • Missing
  • Known

Data: the 11 steps of t3-tutor-loop.html. The prerequisite C15 → C04 comes from the concept file in Spec v0.2. Only the drawing differs between panels; the scenario is unchanged.
