Focus stack. Present-tense. Only where you are now — the dive chain that led here, the live unit + its axes, the next proof, and where you'll return. History folds away. Best for the learner mid-turn; the whole tree is deliberately hidden.
Clean ladder. The full tree, but one line per unit — no expanded detail — so the rails stay short and never cross content. Dives indent on a gold rail; return is a labelled line. Best overview at a glance.
Call stack. The Router's subhole-stack drawn literally, like a debugger. A dive pushes a frame on top; the live frame is the deepest. Returned dives are popped (faded ✓). The ladder rides alongside. Maps 1:1 to the stack table.
Metro line. Units are stations on a line. A dive is a branch line that leaves at the gap station and loops back where it rejoins (the return). You are the train ●. Spatial and memorable; scales to a few dives, not dozens.
Loop trace. Time runs left→right in the exact order the loop ran. Depth is vertical: a dive dips down, a return rises back. One thread through every event. Best for "what actually happened," like an execution trace.
Depth lanes. git-graph columns: each depth is its own vertical lane, so lines never share a corridor. A dive branches to the next lane; a return merges back. All text sits to the right of the lanes — connectors never touch content. The tangle-proof version.
